# Literature

A six-player team card game in your browser: ask, bluff a little, claim sets, and laugh when the table turns. You won't appreciate the game until you play it. 

Practice against five bots, or host a live room and share the code. Nothing to install and no account to create. Use video conferencing service of your choice if you need more in-person feel. If you have 5 people in-person, I would strongly suggest to get a deck and play in-preson, its so much fun. 

The game stays in the tab, no program to run on your computer, no server holding your hand.

Start with [How to play](how-to-play.html), play with bots if its your first time or if you just want to practice.
