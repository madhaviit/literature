# Literature

A six-player team card game in your browser: ask, bluff to mislead a little, claim sets, and laugh when the table turns. You won't appreciate the game until you play it. 

Practice against five bots, or host a live room and share the code (Now, you can have few bots if you are short on players). Nothing to install and no account to create. Use video/audio conferencing service of your choice if you need more in-person feel. If you have 5 people in-person, I would strongly suggest to get a deck and play in-preson, its so much fun. 

Start with [How to play](how-to-play.html), play with bots if its your first time or if you just want to practice.
